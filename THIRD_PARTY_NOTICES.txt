Local modification: native/patches/DobbyAndroid.patch replaces a circular
platform-header dependency with direct POSIX page protection using the runtime
page size. It also makes ARM64 near-hook allocation fail before patching,
preserves a 16-byte relocation span behind a four-byte entry patch, snapshots
recognized literal branch veneers, rejects unsupported overlapping PC-relative
instructions, and checks patch ownership before restoring original bytes.
The patch is applied by native/cmake/Dependencies.cmake.

Source code, the dependency revisions, the Dobby patch and the CMake/Gradle build
scripts are needed to rebuild or relink this prototype with modified libraries.
The native library statically links LGPL components. GitHub prereleases provide
a separate corresponding-source archive with the complete application source,
pinned native library sources, licenses and rebuild/relink instructions. The
module ZIP itself is the binary installation package. Dependency source copies
in the source archive are separate from the checkout locations used by CMake;
follow the archive's instructions to rebuild or relink with modified libraries.

The manager uses AndroidX, Kotlin and kotlinx.coroutines. Their distribution
terms remain applicable. The Gradle wrapper retains its upstream license headers.
