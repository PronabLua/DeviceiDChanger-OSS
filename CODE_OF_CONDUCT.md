# Code of Conduct

This project aims to make technical collaboration respectful and useful for people with different experience levels and backgrounds.

## Expected behavior

- Be considerate, clear, and patient.
- Discuss ideas and technical evidence without personal attacks.
- Accept constructive feedback and correct mistakes.
- Respect privacy and obtain permission before sharing someone else's information.
- Keep issues and reviews relevant to the project.

Harassment, threats, discriminatory abuse, sexual harassment, doxxing, and repeated targeted disruption are unacceptable. These expectations apply to project issues, pull requests, reviews, and other project-managed spaces.

## Reporting and moderation

For an ordinary conduct concern, ask a repository maintainer to review the relevant discussion. Do not repost abusive material or private information unnecessarily. For a sensitive incident, ask for a private contact channel without publishing details; this repository does not designate a separate conduct-reporting email.

Maintainers may edit or remove disruptive content, close or lock discussions, or restrict participation based on the situation. Reports and moderation requests should be handled with care for the privacy of everyone involved. Security vulnerabilities follow [SECURITY.md](SECURITY.md).
