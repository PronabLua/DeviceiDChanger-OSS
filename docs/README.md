# Documentation

The main guides describe the **native Zygisk prototype**. The [legacy WebUI guide](LEGACY_WEBUI.md) covers the upstream implementation separately.

## For users

1. Review [compatibility and limitations](COMPATIBILITY.md).
2. Follow [installation and upgrades](INSTALLATION.md).
3. Use the [companion app guide](USAGE.md).
4. Consult [troubleshooting](TROUBLESHOOTING.md) if an operation fails.

## For contributors

1. Read the [contribution guide](../CONTRIBUTING.md).
2. Set up the [build environment](BUILDING.md).
3. Understand the [architecture](ARCHITECTURE.md) and [root helper interface](HELPER_REFERENCE.md).
4. Run the relevant [tests](TESTING.md).
5. For distribution work, follow [release and source packaging](RELEASING.md).
